# RDF 1.2 on the Wire Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The pod stores and serves RDF 1.2 — triple terms and directional language-tagged strings — as an explicit, versioned act on both sides of the wire, degrading for 1.1 clients instead of breaking them.

**Architecture:** One vocabulary (`RdfVersion`, Concepts' three labels) answers three questions: what a store can hold, what a representation claims, and what a client asked for. `Dataset::rdf_version()` is the only classifier; `RdfVersion::from_media_type` is the only reader of the `version` parameter. The refusal built by shape validation becomes total first (it covers one of two new term kinds today), then conditional. The ground type family in `dataset.rs` grows a recursive variant, which is the only real algorithmic work.

**Tech Stack:** Rust 1.95.0, axum 0.8, oxigraph 0.5.9 with `rdf-12`, `oxrdf` 0.3.3.

**Spec:** [`docs/superpowers/specs/2026-07-30-rdf12-design.md`](../specs/2026-07-30-rdf12-design.md). Section references below (§3.1, §5, …) are to that document.

## Global Constraints

- `Cargo.toml` declares `oxigraph = { version = "0.5.9", features = ["rdf-12"] }` from Task 1 onward. Never rely on `rudof_lib` enabling it transitively (§3.3).
- **Silence means `Rdf11`** (§4). A missing `version` media-type parameter is 1.1 on both the read and the write side — deliberately stricter than RDF 1.2 Concepts, which says absence means 1.2.
- `Dataset::rdf_version()` is the **only** place a dataset's version is classified (§3.1). `RdfVersion::from_media_type` is the **only** place `version=` is read (§4).
- This feature mints **no** vocabulary. `Content-Type` with a `version` parameter and `Link rel="alternate"` are the whole read-side interface (§5).
- The in-band `VERSION` / `@version` Turtle directive is neither required nor emitted (§2.2).
- No new `SparqlStore` implementor. `docs/constraints.md` keeps its one-implementor tripwire.
- After every task: `nix develop -c cargo test` passes and `arch-check` reports 0 violated, 0 broken.
- Commit at the end of every task. Conventional commits.

/// The RDF version labels of [RDF 1.2 Concepts §2.1][labels], verbatim, in
/// that document's containment order: data valid at a lower label is valid
/// at a higher one. `PartialOrd` is derived from the variant order, so the
/// whole capability question is `needed <= available`.
///
/// One type for three roles — what a store can hold
/// ([`SparqlStore::rdf_version`](crate::store::SparqlStore::rdf_version)),
/// what a representation claims (the `version` media-type parameter), and
/// what a deployment declares. Design §3.
///
/// [labels]: https://www.w3.org/TR/rdf12-concepts/#defined-version-labels
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub enum RdfVersion {
    /// RDF 1.1 syntax, without a version directive.
    Rdf11,
    /// RDF 1.2 syntax **without** triple terms — directional
    /// language-tagged strings, and nothing else new.
    Rdf12Basic,
    /// Full RDF 1.2 syntax.
    Rdf12,
}

impl RdfVersion {
    /// The label as it appears in a `version` media-type parameter.
    pub fn label(self) -> &'static str {
        match self {
            Self::Rdf11 => "1.1",
            Self::Rdf12Basic => "1.2-basic",
            Self::Rdf12 => "1.2",
        }
    }

    /// **The only place the `version` media-type parameter is read.** Design
    /// §4, and `docs/constraints.md`. `Content-Type` on write and `Accept`
    /// on read ask the same question of the same syntax; a second reader is
    /// how `1.2` comes to mean one thing on the way in and another on the
    /// way out — the same failure the single q-value parse in
    /// [`ranked_accept`] guards against.
    ///
    /// `None` distinguishes an *unrecognised* label, which §6 answers with
    /// `415`, from an *absent* one, which §4 reads as
    /// [`Rdf11`](Self::Rdf11).
    pub fn from_media_type(mt: &str) -> Option<Self> {
        let mut found = None;
        for p in mt.split(';').skip(1) {
            let Some((name, value)) = p.trim().split_once('=') else {
                return None;
            };
            if !name.trim().eq_ignore_ascii_case("version") {
                continue;
            }
            found = Some(match value.trim() {
                "1.1" => Self::Rdf11,
                "1.2-basic" => Self::Rdf12Basic,
                "1.2" => Self::Rdf12,
                _ => return None,
            });
        }
        Some(found.unwrap_or(Self::Rdf11))
    }
}
```

/// §3.1: the least [`RdfVersion`] under which every term here is
/// expressible.
///
/// **The only place a dataset's version is classified** — see
/// `docs/constraints.md`. Two classifiers is how the write-side check and
/// the read-side projection drift apart, and the drift is silent: both
/// answer, one answers wrong.
///
/// Only the object position needs inspecting for a triple term (subjects
/// are `NamedOrBlankNode`), and only a literal can carry a base direction.
pub fn rdf_version(&self) -> RdfVersion {
    let mut found = RdfVersion::Rdf11;
    for q in &self.0 {
        let here = match &q.object {
            Term::Triple(_) => RdfVersion::Rdf12,
            Term::Literal(l) if l.direction().is_some() => RdfVersion::Rdf12Basic,
            _ => continue,
        };
        found = found.max(here);
        if found == RdfVersion::Rdf12 {
            break;
        }
    }
    found
}
```

Add to `impl Dataset` in `src/dataset.rs`:

```rust
/// §5: this dataset as it can be expressed at `target`.
///
/// The two additions degrade unequally, and that asymmetry is the point.
/// A base direction is presentation metadata on a literal — strip it and
/// the statement survives. A triple term is the object itself: there is
/// nothing to strip, so the triple goes. The result is a **subset** of what
/// was written, never a rewriting of it; merging or approximating would
/// manufacture assertions the document never made, which is the same
/// argument §6.2 of the datasets design makes against merging named graphs
/// into the default one.
pub fn project_to(&self, target: RdfVersion) -> Dataset {
    if self.rdf_version() <= target {
        return self.clone();
    }
    let quads = self.0.iter().filter_map(|q| {
        if target < RdfVersion::Rdf12 && matches!(q.object, Term::Triple(_)) {
            return None;
        }
        let object = match &q.object {
            Term::Literal(l) if target < RdfVersion::Rdf12Basic && l.direction().is_some() => {
                let language = l.language().expect("a directional literal is language-tagged");
                Term::Literal(
                    Literal::new_language_tagged_literal(l.value(), language)
                        .expect("the language tag came off a valid literal"),
                )
            }
            other => other.clone(),
        };
        Some(Quad { object, ..q.clone() })
    }).collect();
    Dataset::new(quads)
}
```

`Dataset` needs `#[derive(Clone)]` if it does not have it.

- [ ] **Step 4: Negotiate the version**

`negotiate` currently returns `Option<Format>`; it becomes `Option<(Format, RdfVersion)>`. Do **not** add a second function beside it — `docs/constraints.md` already pins that there is one content-negotiation path, and the version is negotiated from the same `Accept` list by the same pass. Every media range carries its own parameters, so the version travels with the range that wins, read by `RdfVersion::from_media_type` and defaulting to `Rdf11` per §4.

A range whose version label is unrecognised is *skipped*, not fatal: on the read side another range may still be acceptable, and `406` stays reachable only when nothing is (datasets design §6.3). This differs from the write side, where an unknown label is a `415` because there is no second candidate to fall back to.

Clamp the result to what the resource can offer: the served version is `min(requested, resource.rdf_version())`, so asking for 1.2 of a plain 1.1 resource serves — and advertises — 1.1.
