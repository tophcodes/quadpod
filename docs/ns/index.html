The quadpod vocabulary

https://w3id.org/quadpod/ns#, preferred prefix quadpod:

Terms quadpod mints because no registered vocabulary carries them. A term enters this namespace only when the alternative is a claim a server cannot make in any registered vocabulary. Everything quadpod can say in LDP, WAC, SHACL, PROV-O or schema.org is said there instead.

Machine-readable: quadpod.ttl.

Terms

quadpod:containsGraph (rdf:Property)

Names a graph that the subject's dataset contains and that the representation at hand does not carry.

quadpod uses it as an HTTP link relation (RFC 8288) on a response whose media type has no syntax for named graphs, such as Turtle or N-Triples, served for a resource whose stored form is a dataset. The body is the default graph, and one header names each graph left out, so the response is complete about what it omits:

GET /notes HTTP/1.1
Accept: text/turtle

HTTP/1.1 200 OK
Content-Type: text/turtle
Link: </notes>; rel="https://w3id.org/quadpod/ns#partialDataset"
Link: <urn:example:g1>; rel="https://w3id.org/quadpod/ns#containsGraph"
Link: </notes>; rel="alternate"; type="application/trig"

A client that wants the whole dataset re-requests it in a format that can hold one; those are advertised alongside with rel="alternate".

No registered link relation states that a representation omits part of a resource, which is why this term exists. It follows the shape LDP uses for ldp:constrainedBy: an RDF property that also serves as a link relation.

quadpod:partialDataset (rdf:Property)

States that the representation at hand carries only the default graph of the dataset stored at the subject.

quadpod uses it as an HTTP link relation (RFC 8288), with the resource's own URL as the target, on every response whose media type has no syntax for named graphs and whose resource is stored as a dataset. It is a claim about the representation as a whole and names no parts, so it holds where quadpod:containsGraph cannot: a graph the client named with a blank node has no IRI a header could carry, so a response withholding only such graphs would otherwise state nothing.

GET /credential HTTP/1.1
Accept: text/turtle

HTTP/1.1 200 OK
Content-Type: text/turtle
Link: </credential>; rel="https://w3id.org/quadpod/ns#partialDataset"
Link: </credential>; rel="alternate"; type="application/trig"

That is the deployed case: a Verifiable Credential keeps its proof in a blank-node-named graph, so no graph can be named and this header is the only one stating that the claims arrived without the proof.

The two terms are emitted together and answer different questions. This one says the representation is partial; quadpod:containsGraph says which graphs are missing, for those that can be named.

The namespace resolves through w3id.org, so the terms keep their identity if the hosting moves. Source and issue tracker: github.com/tophcodes/quadpod.
